# 방파제 디펜스 PRD — 문제 풀이 기반 게이미피케이션 웹앱

Oct 30, 2026 · @Jinny

## 1. 개요

**방파제 디펜스**는 초등학생이 교과 문제를 풀어 탱크를 강화하고, 바다에서 몰려오는 괴수로부터 방파제를 지키는 3D 웹 디펜스 게임이다. 문제 풀이는 전투 흐름 속 "출격 점검 → 보급 → 정비 → 복기"라는 군사 정비 컨셉으로 녹아 있으며, **문제를 성실히 풀지 않으면 웨이브를 완료할 수 없다.**

### 1.1 목표

- 학습자가 한 스테이지(3웨이브, 약 12\~15분) 동안 최소 12문제를 자발적으로 풀게 한다.
- 정답은 즉시 체감되는 전투 이득(공격력, 포격 지원, 부품)으로 보상해 "풀고 싶은" 동기를 만든다.
- 찍기·건너뛰기로는 진행이 막히도록 설계해 학습 성실도를 보장한다.
- 격납고 해금·강화로 스테이지 간 장기 동기(수집·성장)를 제공한다.

### 1.2 대상 사용자

| 사용자 | 니즈 | 주요 접점 |
| --- | --- | --- |
| 학생 (초3\~초6) | 재미있게 복습, 성장하는 손맛 | 전투, 격납고, 보스전 |
| 교사 | 학년·학기별 문제 배정, 풀이 기록 확인 | 학년·학기 선택, 결과 리포트 |
| 학부모 | 자녀 학습량·정답률 확인 | 결과 리포트(후순위) |

### 1.3 핵심 설계 원칙

1. **문제는 전투의 일부다** — 문제는 별도 퀴즈 화면이 아니라 "점검·보급·정비·복기"라는 세계관 안의 행동이다.
2. **성실 풀이 게이트** — 웨이브 클리어 조건에 문제 풀이가 포함된다. 몹을 다 잡아도 필수 문제를 풀어야 다음으로 넘어간다.
3. **정답은 즉시, 크게 보상** — 정답 직후 화면 안에서 효과(포격 연출, 버프 아이콘, 부품 획득)가 보인다.
4. **오답은 벌이 아니라 대가** — 오답은 약한 페널티와 해설을 주고, 재도전 기회를 남긴다.
5. **보스는 조준 실력 + 문제 보상의 결합** — 약점을 노려야 이기고, 문제 보상이 약점 공략을 돕는다.

### 1.4 범위

- **v1 포함**: 방파제 방어 모드 스테이지 1\~2(각 3웨이브, 보스 산호 거신·거대 해파리), 격납고(해금·장착·강화), **수학 문제만**, **로컬 저장**. 스테이지 3 이후 카드는 ‘COMING SOON’으로 노출.
- **v1 이후**: 스테이지 3\~5와 ENDLESS, 국어·과학·사회, 계정·서버 저장.
- **제외**: 협동 출격(멀티플레이) — 화면 진입점만 ‘준비 중’으로 노출, 교사 대시보드 고도화, 결제.

## 3. 핵심 게임 루프와 문제 풀이 시스템

한 웨이브는 **출격 점검(전투 준비 문제) → 전투(보급상자 문제) → 전투 복기 → 정비**의 4단계로 돌아간다. 문제는 네 지점에서 나오며, 전투 복기를 통과해야만 웨이브가 "완료"된다.

### 3.1 문제 출제 지점

| 시점 | 이름 | 문제 수 | 정답 보상 | 오답 처리 | 필수 여부 |
| --- | --- | --- | --- | --- | --- |
| 웨이브 시작 전 | 출격 점검(전투 준비) | 3 (포신·장전기·방파제) | 공격력 +10% / 공격속도 +10% / 내구도 +20 | 같은 항목 -15% / -15% / -20 | 필수 (건너뛸 수 없음) |
| 전투 중 | 보급상자 | 웨이브당 2\~4개 낙하 | 부품 또는 포격 지원 (3.3) | 상자 소멸, 해설 노출 | 선택 (단, 성실도 점수에 반영) |
| 모든 몹 처치 직후 | 전투 복기 | 3 | 없음 (3문제를 모두 풀면 웨이브 완료) | 해설 확인 후 다음 문제, 오답 노트에 기록 | **필수 (웨이브 완료 게이트)** |
| 복기 후 | 정비 시간 | 수리 1 + 보너스 최대 3 | 내구도 +30 / 부품 +8, +10, +12 | 보상 없음 | 선택 (단, 버프 유지에 1개 이상 필요) |

### 3.2 출격 점검 (전투 준비 문제)

- 스테이지 선택 후 ‘출격 점검’ 화면에서 3개 카드(포신/장전기/방파제)를 순서대로 푼다. 카드 상태는 대기 → 정답(초록) / 오답(빨강).
- 첫 웨이브는 ‘복습’ 문제(이전 학기·지난 세션 오답), 2·3웨이브는 직전 웨이브에서 배운 단원을 우선 출제한다.
- 결과는 전투 HUD 좌상단에 버프/디버프 칩(예: ‘공격력 +10%’)으로 웨이브 내내 표시된다.

### 3.3 보급상자 (전투 중 문제)

- 웨이브 진행 중 낙하산에 매달린 보급상자가 하늘에서 천천히 내려온다(낙하 8\~12초). 상단에 ‘▼ 보급 상자’ 마커와 레이더 표시.
- 플레이어가 상자를 사격해 낙하산 끝을 맞추면(또는 방파제에 착지하면) 문제 팝업이 열리고, \*\*전투는 슬로모션(0.15배)\*\*으로 전환된다. 바다에 떨어지면 상자는 가라앉는다.
- 상자 종류(낙하산 색으로 구분):

| 상자 | 색 | 정답 보상 |
| --- | --- | --- |
| 부품 상자 | 노랑 | 부품 ⚙ +5\~+15 (문제 난이도 비례) |
| 포격 지원 상자 | 빨강 | 공중 포격: 화면 내 모든 몹에게 최대 HP의 30% 데미지 (보스는 8%, 약점 노출 시간 +3초) |
| 정비 상자 | 초록 | 방파제 내구도 +20 또는 10초간 탄환 장전 무한 |

- 포격 지원 연출: 화면 상단에서 폭격기 실루엣이 지나간 뒤 탄두 궁적 + 바다 물기둥 폭발, 카메라 쉐이크, 몹 머리 위 데미지 숫자.

### 3.4 전투 복기 (웨이브 완료 게이트)

- 모든 몹을 처치해도 웨이브는 바로 끝나지 않고 ‘전투 복기’ 화면으로 넘어간다. 이번 웨이브의 오답과 같은 개념의 문제 3개가 나온다(오답이 없으면 현재 단원 심화 문제).
- **완료 기준: 3문제를 모두 푼다.** 정답 수는 통과 조건이 아니며, 3문제를 다 풀기 전까지 ‘다음 웨이브 시작’ 버튼이 잠긴다.
- **정답률 보상 없음.** 복기는 점수를 따는 시간이 아니라 되돌아보는 시간이다. 부품·버프 보상은 보급상자와 정비 보너스 문제에만 둔다.
- **오답이면 해설 확인 필수.** 틀리면 해설 카드가 열리고 ‘이해했어요’를 눌러야 다음 문제로 넘어간다(해설은 최소 3초 노출). 틀린 개념은 오답 노트에 쌓여 다음 웨이브 출격 점검에 다시 나온다.
- 복기 문제에도 읽기 시간 잠금과 빠른 연타 탐지(3.6)를 똑같이 적용하고, 풀이 기록은 성실도 등급에 반영한다.
- 복기 화면은 웨이브 요약(처치 수, 받은 피해, 풀어난 문제, 오답 개념)을 함께 보여준다.

### 3.5 정비 시간

- 첨부 화면의 ‘WAVE N 방어 성공! · 정비 시간’ 레이아웃을 따른다: 방파제 수리 카드(문제 1개, 내구도 +30) + 보너스 문제 카드(남은 기회 3, 풀수록 보상 증가 +8 → +10 → +12).
- 출격 점검 버프는 정비에서 1문제 이상 맞혀야 다음 웨이브로 이어진다(안내 문구 노출).
- 기체 강화는 여기서 하지 않고, 스테이지 종료 후 격납고에서만 한다.

### 3.6 성실 풀이 장치 (찍기·건너뛰기 방지)

1. **읽기 시간 잠금** — 문제가 뜨면 보기는 글자 수에 비례한 시간(최소 1.5초, 최대 4초) 동안 비활성. 보기는 매번 섞는다.
2. **연속 오답 쿨다운** — 2연속 오답 시 해설 카드를 끝까지 보고 ‘이해했어요’를 눌러야 다음 문제가 열린다.
3. **같은 문제 재출제 금지** — 재도전은 같은 개념의 다른 문제(숫자·보기 변형)로 나온다. 예: 27×4 → 26×4.
4. **성실도 점수** — 웨이브마다 (푼 문제 수, 정답률, 평균 풀이 시간, 빠른 연타 횟수)를 합산해 S/A/B/C 등급을 매긴다. C등급이면 스테이지 별 획득이 제한되고, 다음 스테이지 해금에는 스테이지 평균 B 이상이 필요하다.
5. **입력 이상 탐지** — 0.8초 미만 응답이 3회 연속이면 ‘천천히 읽어보세요’ 안내와 함께 읽기 잠금을 2배로 늘린다.
6. **일시정지·새로고침 우회 방지** — 문제가 열린 상태에서 새로고침하면 같은 문제 상태로 복원된다(세션 저장).

## 4. 전투 시스템

플레이어는 방파제 위에 고정된 탱크 포탑에서 1인칭 시점으로 바다를 바라보며, 수평선에서 다가오는 괴수가 방파제에 닿기 전에 처치한다. 방파제 내구도가 0이 되면 패배다.

### 4.1 조작

| 입력 | PC | 태블릿/모바일 |
| --- | --- | --- |
| 조준 | 마우스 이동 | 화면 오른쪽 드래그 |
| 발사 | 좌클릭 / Space | 발사 버튼 (누르고 있으면 연사) |
| 망원경(확대) | 우클릭, 휠로 배율 2x/4x | 망원경 버튼 + 핀치 |
| 시점 회전 | A / D | 화면 왼쪽 드래그 |
| 일시정지 | P / Esc | 우상단 ⏸ |
| 전체화면 | 우상단 ⛶ | 우상단 ⛶ |

- 조준선 옆에 거리(m)를 표시하고, 사거리 밖이면 ‘사거리 밖 (최대 420m)’를 연한 글씨로 띄운다.
- 포탄은 포물선 탄도 + 비행 시간이 있어, 멀리 있는 적은 이동 방향을 예측해 쏴야 한다(초등학생 난이도를 위해 약한 조준 보정 제공).

### 4.2 HUD

- **좌상단**: STAGE n · 웨이브 n/3, 점수, 부품 ⚙, 남은 괴수 / 그 아래 출격 점검 버프 칩
- **상단 중앙**: 보스 전 HP 바 (보스 웨이브만)
- **우상단**: 전체화면, 일시정지, 반원형 레이더(800m, 몹 빨간 점, 보급상자 노란 점, 보스 큰 점)
- **좌하단**: 방파제 내구도 바 + 수치
- **우하단**: 장착 기체 카드(기체명, 탄종, 공격력, 발/초, 재장전 게이지)
- **하단 중앙**: 조작 힌트 (첫 스테이지만, 3초 후 흐려짐)

### 4.3 웨이브 구성

- 한 스테이지 = 3웨이브. 1·2웨이브는 일반 몹, 3웨이브는 일반 몹 + 보스.
- 웨이브 시작 시 ‘WAVE n / 3’ 타이틀 + 부제(예: ‘수평선에서 괴수들이 다가옵니다’) 2.5초 노출.
- 몹은 수평선 3\~4개 출현 지점에서 시간차로 나오며, 남은 괴수 카운터가 줄어든다.

| 스테이지 | 테마 | 난이도 | 웨이브별 몹 수 | 보스 | 환경 |
| --- | --- | --- | --- | --- | --- |
| 1 | 잔잔한 만 | ★ | 12 / 16 / 20+보스 | 산호 거신 | 저녁 노을, 약한 비 |
| 2 | 안개 해협 | ★★ | 14 / 18 / 22+보스 | 거대 해파리 | 짙은 안개(시야 제한) |
| 3 | 폭풍의 바다 | ★★★ | 16 / 20 / 24+보스 | 낙뢰 강철게 | 폭풍우, 번개, 높은 파도 |
| 4 | 심해 균열 | ★★★★ | 18 / 22 / 26+보스 | 심해 아귀 | 어두운 밤, 수중 발광 |
| 5 | 심연의 왕좌 | ★★★★★ | 20 / 24 / 28+보스 | 심연의 왕 | 붉은 하늘, 용암 균열 |
| ENDLESS | 끝없는 바다 | ∞ | 무한 증가 | 5웨이브마다 랜덤 | 랜덤 |

### 4.4 몹 종류

| 몹 | 특징 | 등장 |
| --- | --- | --- |
| 꼬마 게 | 느리고 약함, 무리로 옵 | 1\~ |
| 해파리 드론 | 공중에 떠서 지그재그 이동 | 2\~ |
| 갑각 게 | 정면 데미지 50% 감소, 측면이 약점 | 3\~ |
| 돌진 상어 | 물속에 숨었다가 빠르게 돌진, 수면 위로 나올 때만 피격 | 3\~ |
| 심해 아귀 새끼 | 발광 미끼로 조준을 헷갈리게 함 | 4\~ |

- 몹이 방파제에 닿으면 내구도를 깎고 사라진다(크기에 따라 -5 \~ -15).
- 처치 시 점수 +100 (대형 +250), 부품 ⚙ +1\~3 드롭.

### 4.5 승패 조건

- **웨이브 완료** = 남은 괴수 0 **그리고** 전투 복기 3문제 모두 풀이(3.4).
- **스테이지 클리어** = 3웨이브 완료. 별점(★ 1\~3)은 남은 내구도 비율 + 성실도 등급으로 산정.
- **패배** = 내구도 0. 패배 화면에서 ‘다시 도전’ 시 해당 웨이브부터 재시작(출격 점검 다시 수행), 획득한 부품의 50%는 유지.

## 5. 보스 시스템

각 스테이지 3웨이브에는 보스가 전용 등장 연출과 함께 나타나며, **약점을 맞히지 않으면 사실상 처치할 수 없도록** 설계한다. 약점 외 부위는 데미지가 10%만 들어간다.

### 5.1 등장 연출 (컷신, 약 6초, 스킵 가능)

1. **전조 (0\~1.5초)** — 3웨이브 일반 몹이 절반 이하로 줄면 발동. 화면이 붉게 물들고 경고 사이렌, 카메라가 미세하게 떨림. 레이더에 큰 점이 깜빡임.
2. **부상 (1.5\~4초)** — 플레이어 조작을 잠금하고 카메라가 수평선으로 드리프트 줌인. 바다가 부풀며 보스가 물기둥을 뚫고 솔아오름. 대형 파도가 방파제로 밀려옴.
3. **타이틀 (4\~5.5초)** — ‘⚠ 산호 거신 출현 ⚠’ 대형 타이틀 + ‘BOSS · 머리를 노리세요!’ 부제. 보스 포효 사운드, 상단 보스 HP 바가 차오름.
4. **복귀 (5.5\~6초)** — 카메라가 포탑 시점으로 돌아오고 조작 재개. 약점 마커가 처음 번쩍임.

- 첫 관람 후 같은 보스는 스킵 가능. 연출 중 몹·보급상자는 일시정지.
- 구현: Three.js 카메라 트랙(키프레임) + 보스 모델 등장 애니메이션 + CSS 타이틀 오버레이를 타임라인 하나로 동기화.

### 5.2 약점 표시

- 보스 이름 위 HP 바와 함께, 약점 부위에 \*\*맥동하는 빛(예: 산호 거신 머리의 청록색 균열 빛)\*\*과 월드 마커(원형 표적 + ‘약점’ 라벨)를 띄운다.
- 조준선이 약점 위에 오면 조준선이 빨간색으로 바뀌고 ‘약점 조준’ 작은 글씨가 뜨며, 망원경(우클릭) 모드에서는 약점 윤곽선이 강조된다.
- 약점 명중 시 노란색 크리티컬 숫자 + ‘WEAK POINT!’ 팝업, 일반 부위 명중 시 회색 숫자 + 튀는 불꽃 이펙트(‘효과가 없다’ 피드백).

### 5.3 약점 판정과 페이즈

| 항목 | 규칙 |
| --- | --- |
| 약점 데미지 | 기본 공격력 × 3.0 |
| 일반 부위 | 기본 공격력 × 0.1 |
| 판정 | 보스 모델에 별도 히트박스(구체/캐슬) 부착, 레이캐스트·포탄 충돌로 부위 판별 |
| 약점 노출 사이클 | 노출 6초 → 방어 4초(갑주 닫힘, 약점 무적) 반복. 방어 중에는 일반 몹을 소환 |
| 페이즈 | HP 66%·33%에서 약점 위치 이동(머리 → 가슴 → 어깨 등). 전환 시 1.5초 미니 연출로 새 약점 알림 |
| 문제 연계 | 보스전 보급상자는 ‘약점 분석 상자’가 추가로 나오며, 정답 시 방어 상태를 강제 해제하고 약점 노출 8초 + 약점 데미지 ×1.5 |
| 보스 공격 | 주기적 파도 공격(내구도 -10), 예고 표시 2초 후 발동. 약점을 맞히면 공격 취소(경직) |

### 5.4 보스 목록

| 스테이지 | 보스 | 약점 1 → 2 → 3 | 특수 패턴 |
| --- | --- | --- | --- |
| 1 | 산호 거신 | 머리 균열 → 가슴 코어 → 등 결정 | 팔을 들어 머리 가리기 |
| 2 | 거대 해파리 | 발광 핵 → 촉수 뿌리 → 상단 돌기 | 안개 속에서 자리 이동 |
| 3 | 낙뢰 강철게 | 눈자루 → 집게 관절 → 배 외골격 틈 | 번개 충전 중에만 약점 노출 |
| 4 | 심해 아귀 | 발광 미끼 → 입 안 → 아가미 | 조명을 끄고 미끼로 유인 |
| 5 | 심연의 왕 | 3개 약점 동시 노출, 순서대로 파괴 | 용암 구역 장판 |

## 6. 격납고 (해금·장착·강화)

스테이지를 클리어하면 격납고에서 새 기체·무기가 해금되고, 모은 부품으로 현재 장착한 무기를 강화한다. 격납고는 출격 준비 화면의 ‘업그레이드’ 카드와 스테이지 선택 화면의 ‘격납고’ 버튼으로 들어간다.

### 6.1 화면 구성

- **중앙**: 스포트라이트가 비친 3D 탱크(드래그로 360° 회전). 강화 시 용접 불꽃·볼트 체결 연출.
- **좌측 패널**: 기체 목록 (보유/잠김, 잠긴 기체는 실루엣 + 해금 조건).
- **우측 패널**: 슬롯별 장착 무기와 강화 단계, 능력치 바(공격력·발/초·사거리·폭발 범위), 강화 버튼.
- **상단**: 보유 부품 ⚙, 보조 기체 슬롯.

### 6.2 해금 규칙

| 클리어 | 해금 |
| --- | --- |
| 시작 | 레드 호넷 (고폭 포탄, 공격력 64, 1.1발/초) |
| 스테이지 1 | 스테이지 2 + 무기 ‘연사 기관포’ + 보조 기체 슬롯 |
| 스테이지 2 | 스테이지 3 + 기체 ‘옐로 레인저’(보조 기체로도 사용) |
| 스테이지 3 | 스테이지 4 + 무기 ‘관통 철갑탄’(약점 데미지 특화) |
| 스테이지 4 | 스테이지 5 + 무기 ‘유도 미사일’ |
| 스테이지 5 | ENDLESS + 기체 ‘블랙 타이탄’ |

- 해금 조건 = 이전 스테이지 클리어 **+ 성실도 평균 B 이상**. 미달이면 ‘복습 훈련’(문제 5개 정답)으로 해금할 수 있다.
- 해금 연출: 스테이지 결과 화면 후 격납고 셔터가 올라가며 새 기체가 모습을 드러내는 3초 연출 + ‘NEW’ 배지.

### 6.3 강화

- 무기마다 Lv.1\~10. 레벨업마다 공격력 +8%, Lv.3/6/9에서 특수 효과(예: 발/초 +0.1, 폭발 범위 +20%, 약점 데미지 +25%).
- 비용: 부품 ⚙ = 30 × 현재 레벨 (Lv.1→2: 30, Lv.9→10: 270).
- **강화 점검 문제**: Lv.5 이상 강화는 문제 1개를 맞혀야 확정된다(오답 시 부품은 돌려받고 재도전). 강화 실패 확률은 두지 않는다.
- 보조 기체는 전투에서 30초마다 자동 지원 사격을 한다.

### 6.4 재화 경제 (부품 ⚙)

| 획득처 | 스테이지당 예상치 |
| --- | --- |
| 몹 처치 드롭 | 40\~70 |
| 보급상자(부품) 정답 | 20\~50 |
| 정비 보너스 문제 | 30\~90 |
| 스테이지 클리어 보상 | 50 × 별점 |

- 목표: 문제로 얻는 부품이 전체의 60% 이상이 되도록 해 ‘문제를 푸는 것이 가장 빠른 성장’이 되게 한다. 스테이지 1회당 대략 Lv.1씩 강화할 수 있는 수준.

## 7. 아트·UI 디자인 가이드

톤은 **‘폭풍우 속 방파제를 지키는 군사 기지’** — 어두운 필름 그레이드 배경 위에 호박색·주황 발광을 포인트로 쓴다. 참고 화면의 사선 컷 패널, 해저드 스트라이프, 도트 그리드 금속 판을 공통 언어로 삼는다.

### 7.1 컬러 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| bg-deep | #0E1316 | 기본 배경 |
| panel | #121A1F (투명도 85%) | 카드·모달 |
| panel-line | #3A4650 | 패널 테두리 1px |
| accent-orange | #F0782A → #C9481A | 주요 CTA(점검 시작, 다음 웨이브) 그라디언트 |
| glow-amber | #FFB067 | LOADING 발광, 문제 모달 테두리 |
| hazard-yellow | #F2B22E | 해저드 스트라이프, 부품 ⚙ 숫자 |
| ok-green | #4FD1A1 | 버프 칩, 내구도 바, 협동 카드 밑줄 |
| info-blue | #4AA8E8 | 업그레이드 카드 밑줄, 레이더 |
| danger-red | #E5484D | 보스 HP, 오답, 약점 조준선 |
| text-cream | #F3E9D2 | 타이틀 |

### 7.2 타이포그래피

- **디스플레이(한글)**: 굵은 헤드라인체(예: 도현체, 김정철체 Bold 등 웹폰트 라이선스 확인 후 확정) — ‘출격 준비’, ‘WAVE 1 방어 성공!’ 등. 크림색 + 아래쪽 드롭 쉐도.
- **디스플레이(영문·숫자)**: 넓은 스텐실형 산세리프(예: Black Ops One, Russo One 계열) — STAGE, WAVE, LOCKED, 점수.
- **본문**: Pretendard — 문제 본문 22\~28px, 보기 20px 이상(초등 저학년 가독성).

### 7.3 컴포넌트 규칙

- **사선 컷 패널**: 오른쪽 아래(또는 왼쪽 위) 모서리를 12px 빗금으로 자른 형태(clip-path). 카드, 버튼, 문제 보기에 공통 적용.
- **모드 카드**(출격 준비): 일러스트 배경 + 굵은 타이틀 + 모드별 컬러 밑줄(주황/파랑/초록). 호버 시 4px 상승 + 밑줄 발광.
- **스테이지 카드**: 3×2 그리드. 잠긴 카드는 흑백 + 어둠 60% + ‘LOCKED’ 스텐실 태그, 별점 난이도 표시.
- **문제 모달**: 주황 1px 발광 테두리, 좌상단 과목 태그(노란 배경), 우상단 맥락(‘출격 점검 2/3 · 장전기 점검’), 보기 2×2 그리드 + 번호 원형 배지. 정답 시 초록 플래시 + 보상 아이콘이 HUD로 날아가는 애니메이션.
- **로딩**: 도트 그리드 금속 배경 + 가로 해저드 스트라이프가 흐르는 애니메이션 + 중앙 ‘LOADING ···’ 발광 태그. 로딩 중 학습 팁 한 줄.

### 7.4 3D 환경·이펙트

- 바다: 반사·법선 맵 물 셰이더(Three.js Water 계열), 태양 반사 하이라이트, 스테이지별 하늘 색.
- 날씨: 비 파티클(GPU 인스턴싱), 스테이지 3 번개 플래시, 스테이지 2 안개(fog).
- 원경: 로우폴리 섬 실루엣, 방파제 테트라포드 + 모래주머니 전경.
- 타격: 포구 화염, 물기둥 탄착, 피격 숫자, 처치 시 파편 + 연기.
- 일러스트(배경·카드): 어두운 폭풍 바다 + 붉은 탱크 + 거대 해양 괴수 세계관을 공통 프롬프트 가이드로 제작해 일관성 유지.

### 7.5 사운드

- BGM: 대기 화면(낮은 앙비언트 + 빗소리), 전투(드럼 중심), 보스(테마 변주 + 코러스), 정비(잔잔한 기지 소음).
- SFX: 포격, 재장전, 피격, 약점 명중(금속성 치링), 낙하산 펼침, 정답 차임, 오답 버저(부드럽게), 사이렌.
- 설정에서 BGM/SFX 개별 볼륨, 교실용 ‘음소거 모드’ 제공.

### 7.6 접근성

- 컬러만으로 구분하지 않는다: 정답/오답은 아이콘(✓/✕) 병기, 상자 종류는 아이콘 병기.
- 화면 흔들림·플래시 끄기 옵션, 문제 텍스트 크게 보기, 문제 읽어주기(TTS, 저학년용).

### 7.7 생성형 도구 제작 파이프라인

일러스트와 3D 모델은 생성형 도구로 초안을 만들고, Blender에서 다듬어 웹용 glTF(GLB)로 내보낸다. Blender에는 Claude를 직접 연결하는 Blender MCP를 달아, 말로 지시해 모델을 정리하게 한다.

| 단계 | 도구 | 결과물 |
| --- | --- | --- |
| 컨셉·배경·카드 일러스트 | Midjourney, Scenario, Leonardo.Ai | 모드 카드, 스테이지 카드, 로비 배경, 3D용 컨셉 시트 |
| 이미지 → 3D 모델 | Meshy, Tripo, Rodin(Hyper3D) | 탱크·몹·보스 메시 + PBR 텍스처(GLB) |
| 다듬기·최적화 | Blender + Blender MCP(Claude가 Blender를 직접 조작) | 폴리곤 감축, 약점 부위 분리, 리깅, Draco 압축 GLB |
| 하늘·재질 | Poly Haven(무료 HDRI·텍스처, Blender MCP에서 바로 불러옴) | 바다 하늘, 방파제 콘크리트·금속 재질 |

1. **아트 바이블 먼저** — 7.1 컬러, 톤 키워드, 참고 이미지를 한 문서로 묶고, 모든 생성 프롬프트에 같은 스타일 문구를 붙여 일관성을 지킨다.
2. **3D용 컨셉 이미지** — 단색 배경, 3/4 뷰, 모델 하나만 담아 생성한다. 이런 이미지가 이미지→3D 변환 품질이 가장 좋다.
3. **이미지 → 3D** — Meshy·Tripo로 여러 개를 뽑아 고른다. 보스처럼 품질이 중요한 모델은 Rodin도 비교한다.
4. **Blender 정리 (Claude에게 지시)** — 폴리곤 목표(제안: 몹 3천\~5천, 보스 2만\~3만 삼각형), 약점 부위를 별도 오브젝트로 분리해 이름 규칙(예: weak\_head, weak\_core)을 붙인다. 게임은 이 이름으로 약점 히트박스를 자동 생성한다.
5. **내보내기** — GLB + Draco 압축, 텍스처 1K\~2K.

- 라이선스: 생성형 도구 결과물의 상업 이용·배포 조건은 도구와 요금제마다 다르다. 사용 전 약관을 확인하고, Sketchfab 모델은 개별 라이선스를 확인한다.
- 기존 게임·영화의 캐릭터나 실존 탱크 디자인을 그대로 따라 하는 프롬프트는 쓰지 않는다.

## 8. 문제 데이터·학습 설계

문제는 학년·학기·과목·개념 태그로 관리하고, 출제 지점마다 다른 선택 규칙을 쓴다. 출격 준비 화면의 ‘학년·학기 바꾸기’로 문제 세트를 바꾼다.

### 8.1 문제 스키마

```json
{
  "id": "m3-1-mul-027",
  "grade": 3, "semester": 1,
  "subject": "수학", "unit": "곱셈", "concept": "(두 자리 수)×(한 자리 수)",
  "difficulty": 2,
  "type": "multiple_choice",
  "stem": "연필이 한 상자에 27개씩 들어 있습니다. 4상자에는 모두 몇 개입니까?",
  "choices": ["108", "111", "106", "107"],
  "answer": 0,
  "explanation": "27×4 = 20×4 + 7×4 = 80 + 28 = 108",
  "variantOf": "m3-1-mul-template-01",
  "minReadSec": 2.5
}
```

- 유형: 객관식 4지선다(v1), OX, 숫자 입력(v1.1), 순서 맞추기(v2).
- **변형 템플릿**: 수학은 숫자 자리를 변수로 두고 오답 보기를 흔한 실수 규칙(받아올림 누락 등)로 자동 생성해 재출제용 유사 문제를 만든다.

### 8.2 출제 지점별 선택 규칙

| 지점 | 난이도 | 출제 우선순위 |
| --- | --- | --- |
| 출격 점검 | 쉬움\~보통 | 지난 세션 오답 → 이전 단원 복습 |
| 보급상자 | 상자 종류별 (포격 지원은 보통 이상) | 현재 단원, 목표 정답률 70\~80% |
| 전투 복기 | 오답과 동일 개념 | 이번 웨이브 오답의 변형 → 현재 단원 심화 |
| 정비 보너스 | 점점 상승 (보상도 상승) | 도전 문제 |
| 격납고 강화 | 보통 | 누적 오답 노트 |

- 난이도 자동 조절: 최근 10문제 정답률이 90% 이상이면 한 단계 올리고, 50% 미만이면 한 단계 내린다.
- 한 세션 안에서 같은 문제 ID는 다시 나오지 않는다(변형만 허용).

### 8.3 오답 노트와 해설

- 오답은 ‘오답 노트’에 개념 단위로 쌓이고, 변형 문제를 2번 연속 맞히면 졸업한다.
- 해설은 한두 줄의 풀이 과정 + (있으면) 그림. 오답 보기를 골랐을 때 왜 틀렸는지 한 줄 피드백(예: ‘111을 골랐다면 7×4를 31로 계산했을 수 있어요’).

### 8.4 콘텐츠 규모 (v1)

- v1은 **수학만**. 초3\~초6 학기별 8개 세트, 첫 배포는 3학년 1·2학기 세트부터.
- 학기당 최소 120문항(변형 템플릿 제외). 스테이지 1\~2 한 번 완주에 약 50문제를 쓴다.
- 수학은 변형 템플릿(숫자 자동 생성) 비중을 높여 문항 제작 부담을 줄인다.
- 문항은 CSV/JSON으로 작성해 앱에 포함(로컬)한다. 검수 상태(초안/검수/배포)는 제작용 시트에서 관리.

## 9. 기술 요구사항·데이터 모델

설치 없이 학교 크롬북·태블릿에서 돌아가는 웹앱이어야 하므로, WebGL 3D + DOM UI 오버레이 구조로 만든다.

### 9.1 기술 스택 (제안)

| 영역 | 선택 | 비고 |
| --- | --- | --- |
| 프레임워크 | React + TypeScript + Vite | UI 화면·모달은 React |
| 3D | Three.js (react-three-fiber) | 물 셰이더, 파티클, 보스 연출 카메라 트랙 |
| 물리·판정 | 자체 탄도 계산 + 레이캐스트, 보스 부위별 히트박스 | 물리 엔진은 불필요 |
| 상태 관리 | Zustand (게임 상태 머신) | 아래 9.3 |
| 애니메이션 | GSAP 또는 Framer Motion | 타이틀·해금·보상 연출 |
| 사운드 | Howler.js |  |
| 백엔드 | v1: 브라우저 IndexedDB(로컬 저장) · v2: Supabase 또는 Firebase | v1은 서버 없음, 기록 내보내기/가져오기로 백업 |
| 배포 | Vercel / Netlify | 에셋 CDN |

### 9.2 성능·호환

- 목표: 크롬북(통합 GPU)에서 45fps 이상, 최초 로딩 5초 이내(4G 기준 첫 화면), 전투 에셋 총 25MB 이하.
- 그래픽 품질 자동 단계(낮음/보통/높음): FPS가 40 미만으로 3초 지속되면 물 반사·비 파티클 수를 낮춘다.
- 모델 glTF + Draco 압축, 텍스처 KTX2, 스테이지별 지연 로딩.
- 브라우저: Chrome/Edge/Safari 최신 2버전, iPad, 가로 화면 고정(세로면 ‘기기를 돌려주세요’ 안내).

### 9.3 게임 상태 머신

`LOADING → LOBBY(출격 준비) → STAGE_SELECT → PRE_CHECK(출격 점검) → WAVE_INTRO → COMBAT ⇄ SUPPLY_QUIZ → (보스 웨이브: BOSS_INTRO → COMBAT) → DEBRIEF(전투 복기) → MAINTENANCE(정비) → 다음 웨이브 또는 STAGE_RESULT → HANGAR`

- COMBAT→DEBRIEF 전환은 남은 괴수 0일 때만, DEBRIEF→MAINTENANCE는 복기 3문제를 모두 풀고 오답 해설을 확인했을 때만 허용.
- 모든 상태는 로컬 저장소에 스냅샷해 새로고침·네트워크 끊김 후 이어하기.

### 9.4 데이터 모델

| --- | --- |

| Progress | userId, stageId, cleared, stars, bestScore, diligenceGrade |
| Inventory | userId, parts, ownedVehicles\[\], ownedWeapons\[\], equipped{main, sub, weapon} |
| WeaponLevel | userId, weaponId, level |
| Question | id, grade, semester, subject, unit, concept, difficulty, stem, choices\[\], answer, explanation, variantOf |
| Attempt | id, userId, questionId, context(점검/보급/복기/정비/강화), stageId, wave, choice, correct, responseMs, createdAt |
| WrongNote | userId, concept, lastWrongAt, streakCorrect |
| Session | id, userId, stageId, wave, state, buffs, hp, snapshot(json) |

### 9.5 보안·개인정보

- v1은 서버가 없어 정답 데이터가 앱 안에 들어 있다. 정답은 문항별 해시로 저장해 개발자 도구로 쉽게 보이지 않게 한다(완전한 차단은 아님, v2에서 서버 판정).
- 진행·풀이 기록은 IndexedDB에 저장한다. 브라우저 데이터 삭제나 기기 변경 시 사라지므로 ‘기록 내보내기/가져오기’(JSON 파일)를 제공한다.
- 학교 공용 기기 대비: 시작 화면에서 닉네임 프로필을 고르고(기기당 최대 30명), 프로필별로 저장한다.
- 법정대리인 동의는 학기초 학교에서 받은 상태다. v1은 개인정보를 기기 밖으로 보내지 않는다.
